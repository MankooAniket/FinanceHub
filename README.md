# 💰 FinanceHub

> **FinanceHub — Your Money, Organized.**

A full-stack personal finance management platform that helps users track income, manage expenses, visualize spending trends, and maintain financial discipline — all in one place.

Built with a modern MERN-style architecture and secure JWT authentication.


## 🚀 Live Overview

FinanceHub allows users to:

- 🔐 Register & Login securely
- 📊 View financial dashboard analytics
- 💵 Add, edit, and delete income & expenses
- 📈 Analyze monthly financial trends
- 🥧 Visualize category-wise expense breakdown
- 🌍 Switch between currencies
- 🔒 Access protected routes with JWT authentication
- 🔑 Reset password securely

## 📊 Core Features

### 🔐 Authentication System
- JWT-based login
- Protected routes middleware
- Email verification flow
- Forgot & Reset password functionality

### 📈 Dashboard Analytics
- Total income & expense tracking
- Current balance calculation
- Monthly summary insights
- Last 6 months bar chart
- Expense category pie chart

### 💳 Financial Management
- Add / Update / Delete income
- Add / Update / Delete expenses
- Category-based tracking
- Clean transaction history

### 🌍 Currency Support
- Multi-currency conversion
- Real-time formatted amounts
- INR, USD, EUR, GBP, JPY, AUD support


## 🔒 Security Implementation

- Passwords hashed using bcrypt
- JWT token expiration (2 days)
- Middleware-based route protection
- Role-based access control
- Email verification guard
- Token-based password reset system
